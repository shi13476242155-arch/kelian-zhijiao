# 课链智教——基于多智能体协同的初中信息科技AI备教学评一体化系统

一套面向初中信息科技课程的双端AI备教学评一体化系统。教师端负责智能备课、资源修订、质量检测和多格式导出；学生端负责课堂资源包导入、任务学习、测评完成和 AI 伴学互动。系统通过标准化 JSON 数据包实现双端数据流转，形成"课前智能备课—课中学习记录—课后学情分析"的完整教学闭环。

## 快速开始

### 环境要求

- Node.js 20 或更高版本
- Windows 10 / Windows 11
- Chrome、Edge 等现代浏览器

### 安装与启动

```bash
# 1. 安装依赖（首次运行）
npm install

# 2. 启动开发环境
npm run dev
```

启动成功后：
- **教师端**：http://localhost:5173
- **学生端**：http://localhost:5174
- **后端服务**：http://localhost:3000

### 构建检查

```bash
npm run build
```

## 核心功能

### 教师端
- **新建课例**：输入教学需求，支持五种课型、AI自动建议、个性化生成向导
- **备课工作台**：AI生成/本地生成完整课堂资源包，支持直接编辑、AI修订助手
- **资源检测**：七维度质量评估 + 核心素养证据链可视化
- **资源导出**：Word (.docx)、HTML 课堂页、JSON 资源包三种格式
- **学情分析**：导入学生数据，生成班级分析和教学改进建议
- **精品案例**：内置可复用课例，一键载入编辑
- **课程数据库**：192条教学指南条目，支持搜索、导入导出和维护

### 学生端
- **资源包导入**：上传教师端导出的 JSON 课堂资源包
- **任务单**：查看学习目标，在线填写任务回答，支持图片上传
- **测评题**：单选题、判断题、简答题、分析题在线作答
- **AI 伴学**：苏格拉底式学习引导，不直接给答案
- **学习数据导出**：生成完整学习数据 JSON，供教师学情分析

### AI 多智能体
- 资源包生成智能体、教学设计起草智能体、AI修订智能体、学情分析智能体、AI伴学智能体
- 所有智能体支持 OpenAI 兼容协议（DeepSeek、通义千问等）
- AI 不可用时自动回退本地规则引擎，确保系统始终可运行
- 严格遵循"AI建议，教师确认"原则

## 技术栈

React 18 · TypeScript 5 · Vite 5 · Tailwind CSS 3 · Express 4 · docx · Node.js 20+

## 设计原则

- **本地可运行**：内置轻量数据库、无需云端服务、无需账号系统
- **教师可控**：AI生成内容必须经过教师确认才能使用
- **数据闭环**：JSON数据包在教师端和学生端之间流转
- **标准兼容**：AI接口采用OpenAI兼容协议，不绑定特定模型
- **教育为本**：以课标为依据、以核心素养为纲、以证据为中心
