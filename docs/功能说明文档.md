# 课链智教功能说明文档

## 一、系统概述

课链智教——基于多智能体协同的初中信息科技AI备教学评一体化系统，是一套面向初中信息科技课程的双端智能教学系统。系统由**教师端（备课工作台）**和**学生端（课堂学习端）**组成，通过标准化 JSON 数据包实现双端数据流转，形成"课前智能备课—课中学习记录—课后学情分析"的完整教学闭环。

- **教师端**：浏览器访问 `http://localhost:5173`（9个功能页面，约3700行）
- **学生端**：浏览器访问 `http://localhost:5174`（约910行，含Electron桌面壳）
- **后端服务**：`http://localhost:3000`（7个API接口 + LangGraph 6节点SSE工作流）

系统约7100行代码，无需数据库和云服务，本地单机即可完整运行。

## 二、教师端功能详述

教师端共包含 9 个功能页面，按备课流程组织为四大导航分组。

### 2.1 工作台首页

- **三大入口卡片**：新建课例、继续备课（上次课例）、精品案例
- **最近课例状态栏**：课例名称、资源状态（AI初稿/教师修改版/教师确认版）、最后保存时间
- **快捷操作区**：根据当前资源状态智能推荐下一步（继续编辑 / 资源检测 / 导出资源）

### 2.2 新建课例

**第一步 — 基本信息**：

| 字段 | 说明 |
|------|------|
| 课题名称 | 本课教学内容名称 |
| 年级 | 七年级 / 八年级 / 九年级（自动映射课程模块） |
| 课程模块 | 互联网应用与创新 / 物联网实践与探索 / 人工智能与智慧社会 |
| 课时数 | 1课时 / 2课时 / 自定义 |
| 课堂类型 | 新知建构课 / 项目实践课 / 实验探究课 / 技能应用课 / 跨学科主题课 |
| 资源生成范围 | 只生成教学设计 / 生成完整课堂资源包 |

**五种课型差异化流程**：

| 课型 | 教学流程 |
|------|----------|
| 新知建构课 | 真实情境→问题分解→原理探究→模型建构→体系建构→迁移应用 |
| 项目实践课 | 问题驱动→需求分析→方案设计→迭代优化→成果展示→反思评价 |
| 实验探究课 | 问题驱动→猜想假设→实验设计→解释论证→评估交流→迁移拓展 |
| 技能应用课 | 任务驱动→范例解析→模仿操作→变式练习→技能整合→综合创新 |
| 跨学科主题课 | 真实问题→跨科探究→方案设计→作品创作→展示评价→拓展反思 |

**学情与条件**：学生基础描述、设备条件描述，支持「AI 帮我写」自动生成。

**第二步 — 教学设计要点**：

- 教学目标、教学重点、教学难点（支持 AI 起草）
- 7个个性化生成标签：项目式学习、跨学科融合、小组协作、真实情境、计算思维、交互性强、工程实践
- 实时侧边栏显示当前配置建议
- 所有数据自动保存至 localStorage

### 2.3 备课工作台（核心页面）

#### 2.3.1 双模式资源生成

**快速生成**：单次 POST 请求调用 `/api/ai/generate-resource`，15-30秒完成全部资源生成。

**深度生成（SSE工作流）**：通过 Server-Sent Events 调用 `/api/ai/generate-workflow`，执行完整的 6 节点 LangGraph 智能体工作流：

| 节点 | 功能 | 容错 |
|------|------|------|
| analyzeNeeds | 分析课例：核心知识点、学生准备度、设备约束、推荐策略 | 规则引擎默认值 |
| alignCurriculum | 匹配2022版课标、TPACK七维度分析、核心素养映射 | 规则引擎默认值 |
| generateActivities | 生成教学环节、问题链、任务单、评价设计、板书、反思建议 | 规则引擎6环节流程 |
| generateAssessments | 4层分层测评题 + 学情诊断模板 | 规则引擎默认题目 |
| evaluateConfidence | 7维度质量评估 + 4条核心素养证据链 + 置信度评分 | 默认置信度 |
| assembleResource | 组装完整 ClassroomResourcePackage | — |

工作流通过 SSE 事件（`progress`/`result`/`fallback`/`error`/`done`）实时推送进度，预计2-3分钟完成。支持三层容错：节点级回退→图级回退→前端本地生成。

#### 2.3.2 五模块资源切换

1. **教学设计**：课标分析、学情分析、教学方法、教学目标（四条核心素养）、重难点、教学流程（6环节表格）、问题链、评价设计、板书设计、反思建议
2. **学习任务单**：学习目标、情境导入、任务步骤、学法指导、操作记录、课堂评价、课堂反思
3. **分层测评题**：单选题(2)、判断题(1)、简答题(1)、分析题选做(1)
4. **学情诊断表**：评价维度、数据来源、数据追踪、诊断规则、输出结果
5. **课堂材料**：补充教学素材与资源

#### 2.3.3 直接编辑与课型切换

- 点击任意内容块直接编辑，无需进入单独编辑模式
- 支持中途切换课型，教学流程自动更新
- 点击「保存修改」→ 资源状态更新为「教师修改版」
- 点击「确认定稿」→ 资源状态更新为「教师确认版」

#### 2.3.4 AI 修订助手

对选中内容块提供局部修订建议，教师确认后才应用。

**7个内置快捷修订方向**：

| 方向 | 说明 |
|------|------|
| 优化教学流程 | 调整环节顺序或活动设计 |
| 增加教师追问 | 补充关键问题和引导性提问 |
| 降低难度 | 简化表述、增加类比和支架 |
| 增加过程性评价 | 补充学习证据采集点 |
| 改得更具体 | 将笼统表述转为可操作描述 |
| 增强情境关联 | 让任务更贴近真实生活 |
| 补充学科核心素养 | 显性标注素养培养点 |

支持自定义修订需求输入。修订结果以**Diff预览**展示（原文红色、建议绿色、理由说明），教师确认方应用。

### 2.4 资源检测

- **总体置信度**：环形图展示综合质量分数
- **导出建议**：绿/黄/红三色灯
- **七维度评估**：课标一致性、核心素养达成度、学情贴合度、活动可操作性、资源完整度、课型匹配度、逻辑连贯性
- **4条核心素养证据链**：目标→活动→任务证据→测评证据→评价方法，每节点绿/黄/红状态
- 平均分、分布统计、最薄弱维度
- 仅教师确认版且置信度达标时建议导出

### 2.5 资源导出

| 格式 | 用途 | 技术 |
|------|------|------|
| Word (.docx) | 打印提交、教学存档 | docx 库，含标题样式、流程表格、7个正式章节 |
| HTML | 课堂大屏展示 | 内联样式，浏览器直接打开 |
| JSON | 学生端导入 | 完整结构化 ClassroomResourcePackage |

支持正式导出（教师确认版）和草稿导出。版本追踪：资源修改后提示重新导出。

### 2.6 学情分析

- 批量上传学生端导出的学习数据 JSON
- **班级总览**：人数、任务完成率、测评完成率、主要薄弱点
- **核心素养表现**：四个维度班级整体评述
- **三层学生分层**：稳定掌握组 / 需要支架组 / 继续观察组
- **薄弱点优先级排序**：全班薄弱维度的优先改善建议
- **教学改进建议**：重点回顾知识点、活动调整方向、个别关注学生

### 2.7 精品案例

- **案例1**「数据分包灵活传」（七年级，新知建构课）
- **案例2**「智能浇花小管家」（八年级，项目实践课）
- 一键载入为可编辑新课例

### 2.8 课程数据库

- 192条内置教学指南条目，覆盖七/八/九年级三大模块
- 按年级/模块分组浏览、关键词搜索
- 支持新增、编辑、删除、JSON导入/导出
- AI 生成时自动加权匹配最相关条目作为课标依据

### 2.9 系统设置

- AI 模型配置（API Key、Base URL、Model Name）+ 测试连接
- 教师信息与默认偏好（年级、课时、课型、设备条件、导出风格）
- 教学偏好多选、学生填写要求开关
- 数据管理（清除课例、恢复默认、导出/导入设置）

## 三、学生端功能详述

学生端采用移动端优先设计（320px宽度），也可通过 Electron 打包为桌面应用。

### 3.1 准备页面

- 上传教师端导出的 JSON 资源包
- 填写学生信息（班级、姓名、学号）
- AI 伴学设置（可折叠，API Key/接口/模型配置）
- 资源包已加载且信息完整后「开始学习」按钮激活

### 3.2 学习页面（三个标签页）

**任务单标签页**：
- 展示学习目标、情境导入、学习任务（编号卡片）
- 每个任务提供文本输入框
- 含「流程图/示意图」关键词的任务支持图片上传（PNG/JPG/GIF，base64编码）
- 图片预览放大及移除

**测评题标签页**：
- 单选题（点击选择A/B/C/D）
- 判断题（对/错按钮）
- 简答题（文本输入）
- 分析题选做（文本输入，标注选做）

**AI伴学标签页**：
- 聊天界面，苏格拉底式引导
- 五层约束：角色层（耐心学习伙伴）、行为层（不给答案、启发提问）、格式层（3-5句/回复）、知识层（附带课题上下文）、伦理层（关注信息社会责任）
- 上下文感知：每次对话附带课题、年级、当前任务、学习目标、学法指导
- AI 不可用时自动回退至规则引擎引导回复

### 3.3 学习进度条

顶部实时显示任务完成进度和测评完成进度。

### 3.4 下课与数据导出

导出的 `StudentLearningData` JSON 包含：
- 学生信息、课例信息、学习时间
- 所有任务回答（含 base64 图片）
- 所有测评作答（含正确答案）
- 完整 AI 伴学对话历史
- 进度统计和诊断信号（概念理解、过程表达、迁移能力、责任意识）

### 3.5 Electron 桌面壳

`apps/student/electron/main.ts` 将学生端打包为桌面应用：
- 窗口 400px 宽，屏幕高度 92%，位于右侧
- 支持开发服务器和生产构建两种模式

## 四、后端服务功能

### 4.1 API 接口

| 接口 | 方法 | 功能 |
|------|------|------|
| `/api/health` | GET | 服务健康检查 |
| `/api/app-info` | GET | 返回系统名称、版本和功能列表 |
| `/api/ai/generate-resource` | POST | AI 生成完整课堂资源包（快速模式） |
| `/api/ai/generate-workflow` | POST | **SSE 流式 LangGraph 6节点智能备课工作流（深度模式）** |
| `/api/ai/test-connection` | POST | 测试 AI 模型连接 |
| `/api/ai/draft-design-points` | POST | AI 起草教学目标和重难点 |
| `/api/ai/student-assistant` | POST | 学生端 AI 伴学对话 |

### 4.2 LangGraph 工作流架构

基于 `apps/server/src/workflow/` 目录实现的 6 节点 StateGraph：

| 文件 | 职责 |
|------|------|
| `state.ts` | 工作流状态类型定义 (100行) |
| `graph.ts` | 图组装：6节点 DAG 编排 + SSE 发送 (136行) |
| `sse.ts` | SSE 事件写入辅助 (42行) |
| `fallback.ts` | 二级回退：单次 AI 调用兜底 (93行) |
| `prompts/systemPrompts.ts` | 5个节点的系统提示词 (146行) |
| `prompts/userPromptBuilders.ts` | 5个节点的用户提示词构建函数 (171行) |
| `nodes/analyzeNeeds.ts` | 需求分析节点 (77行) |
| `nodes/alignCurriculum.ts` | 课标对齐节点 (117行) |
| `nodes/generateActivities.ts` | 活动生成节点 (195行) |
| `nodes/generateAssessments.ts` | 测评生成节点 (130行) |
| `nodes/evaluateConfidence.ts` | 置信度评估节点 (116行) |

### 4.3 AI 配置与容错

- 兼容 OpenAI 协议，支持 DeepSeek、通义千问、智谱GLM 等
- 配置优先级：请求体参数 > 环境变量 > 本地规则引擎
- 三层容错：节点级回退（AI失败→规则引擎）→ 图级回退（工作流失败→单次调用）→ 前端级回退（后端不可用→前端本地生成）
- 支持 `response_format: json_object`，遇到不支持时自动回退至纯文本模式

## 五、数据流转闭环

```
教师创建课例 → AI生成资源包 → 教师修改确认 → 资源质量检测
    → 导出JSON资源包 → 学生端导入 → 学生完成学习
    → 学生导出学习数据 → 教师上传学情数据 → 生成分析报告 → 教学改进
```

整个闭环无需数据库服务器，所有数据通过 JSON 文件在教师端和学生端之间流转。

## 六、系统特色

### 6.1 五种课型差异化生成

根据教师选择的课堂类型，系统生成对应教学流程、方法和测评风格，而非单一模板。

### 6.2 双层 AI 生成架构

- **快速模式**：单次API调用，15-30秒完成，适合初步预览
- **深度模式**：6节点 LangGraph SSE 工作流，2-3分钟逐步生成，质量更高，实时可视化进度

### 6.3 三层内容架构

- **主编辑层**：教师直接使用的课堂资源（教学设计、任务单、测评题、诊断表）
- **依据辅助层**：课标依据、TPACK分析、素养证据链（右侧面板展示）
- **检测导出层**：资源质量检测、多格式导出

### 6.4 AI 可控修订机制

AI 修订建议不自动覆盖教师内容，需教师确认后应用。资源状态追踪（AI初稿→教师修改版→教师确认版）确保教师保持最终控制权。

### 6.5 无数据库架构

全部数据存储在浏览器 localStorage 和 JSON 文件中，零部署门槛。

### 6.6 课程数据库（192条目）

内置结构化课目数据，覆盖初中三个年级全部模块，作为 AI 生成的课标依据。

### 6.7 三层容错体系

AI不可用时逐级回退：节点级→图级→前端级，确保系统始终可运行。
