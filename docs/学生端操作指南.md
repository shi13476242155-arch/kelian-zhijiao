# 课链智教学生端操作指南

## 一、启动

浏览器访问 `http://localhost:5174`，进入学生端。学生端采用手机形态设计（320px宽度），适合在机房浏览器中使用。也可通过 Electron 打包为桌面应用。

课前准备：从教师处获取**课堂资源包 JSON 文件**。

## 二、操作流程

### 第一步：上传资源包

1. 在准备页面点击「上传教师资源包 JSON」
2. 选择教师提供的 `.json` 文件
3. 上传成功后显示课例信息（课题、年级、模块、课时）

> 如果上传后无显示，说明文件格式不对。请确认是教师端导出的**课堂资源包** JSON。

### 第二步：填写信息

输入班级（如"七（3）班"）、姓名、学号。

### 第三步：开始学习

确认资源包已上传、信息已填完后，点击「开始学习」。系统自动记录学习开始时间。

## 三、学习页面操作

### 3.1 完成任务单

点击「任务单」标签页：
- 阅读学习目标和情境导入
- 按任务一→任务二→任务三顺序完成，在文本框中填写回答
- 含「流程图/示意图/结构图」关键词的任务可拍照上传（PNG/JPG/GIF），上传后可点击放大
- 参考学法指导获取提示
- 填写课堂评价和课堂反思

### 3.2 完成测试题

点击「测试题」标签页：

| 题型 | 操作方式 |
|------|----------|
| 单选题（2题） | 点击选择 A/B/C/D |
| 判断题（1题） | 点击「对」或「错」 |
| 简答题（1题） | 文本框中输入回答 |
| 分析题选做（1题） | 文本框中输入，可不做 |

作答建议：简答题尽量写清楚推理过程，不只是结论。

### 3.3 AI 伴学

点击「AI 伴学」标签页，在输入框中提问。

**AI伴学能做的**：帮你理清思路、用提问引导思考、与你讨论理解

**AI伴学不会做的**：直接给你答案、替你完成任务

**建议提问方式**：

| 场景 | 示例 |
|------|------|
| 不知如何开始 | "任务一要求分析数据包传输过程，我不知道从哪里入手" |
| 理解概念 | "分包和重组是什么意思，能帮我理解一下吗" |
| 整理思路 | "我观察到了这些现象，但不知道怎么组织成答案" |
| 联系实际 | "这个过程在日常生活中有类似的例子吗" |

**使用建议**：先自己思考再求助；问具体问题而非笼统问"怎么做"。每节课建议互动3-5次。

### 3.4 查看进度

顶部进度条实时显示任务完成进度和测评完成进度，注意合理安排时间。

## 四、下课与导出

完成所有任务和测评后：

1. 点击「下课并导出学习数据」
2. 系统自动下载 JSON 文件（含任务回答、测评作答、AI对话记录、进度统计）
3. 将文件**提交给教师**

## 五、注意事项

- 学习过程自动保存在浏览器中，刷新不丢失
- **务必在下课前导出**，关闭页面后未导出的数据可能丢失
- 图片建议单张不超过2MB
- 分析题（选做）可根据剩余时间决定是否作答
- AI伴学是辅助工具，认真对待引导问题有助于深入理解

## 六、常见问题

**Q：上传资源包没反应？** 请确认是教师端导出的课堂资源包JSON，不是学生数据包。

**Q：AI伴学没回复？** 可能是后端AI服务未配置，不影响任务单和测评题完成，继续学习即可。

**Q：忘记导出就关了页面？** 未导出的数据无法恢复，请每次下课务必点击导出按钮。
