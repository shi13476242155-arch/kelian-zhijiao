# 课链智教安装与快速开始

## 一、运行环境

- 操作系统：Windows 10 / Windows 11
- Node.js：20.x 或更高版本
- 浏览器：Chrome、Edge 等现代浏览器
- 网络：本地运行不依赖外网；如启用真实 AI 接口，需能访问所配置的模型服务

## 二、项目结构

```
kelian-zhixue/
├── apps/
│   ├── web/          # 教师端（端口 5173）
│   ├── student/      # 学生端（端口 5174）+ Electron 桌面壳
│   └── server/       # 后端服务（端口 3000）+ LangGraph AI 工作流
├── packages/
│   └── shared/       # 共享 TypeScript 类型定义
├── samples/          # 样例资源包
├── docs/             # 项目文档
├── .env.example      # 环境变量模板
└── package.json      # monorepo 根配置
```

## 三、安装

```bash
# 1. 进入项目目录
cd kelian-zhixue

# 2. 安装依赖（首次运行必需）
npm install
```

## 四、启动

```bash
# 开发模式（同时启动教师端、学生端、后端）
npm run dev
```

启动成功后：
- 教师端：`http://localhost:5173`
- 学生端：`http://localhost:5174`
- 后端健康检查：`http://localhost:3000/api/health`

## 五、AI 模型配置（可选）

系统内置本地规则引擎，不配置 AI 模型也可完整体验全部功能。如需启用真实 AI：

1. 打开教师端 → 系统设置
2. 填写 API Base URL（如 `https://api.deepseek.com`）
3. 填写 Model Name（如 `deepseek-chat`）
4. 填写 API Key
5. 点击「测试连接」验证

配置存储在浏览器 localStorage 中，不提交至代码仓库。也可通过 `.env` 文件配置环境变量（参考 `.env.example`）。

## 六、构建

```bash
npm run build
```

构建通过表示教师端、学生端、后端和共享类型均可正常打包。

## 七、快速体验流程

1. 教师端 → 精品案例 → 载入「数据分包灵活传」
2. 进入备课工作台 → 点击「生成课堂资源包」
3. 查看教学设计、任务单、测评题等完整资源
4. 资源检测 → 查看七维度质量评估
5. 导出 JSON 资源包
6. 学生端 → 上传刚导出的 JSON → 填写学生信息 → 开始学习
7. 完成任务单、测评题、AI 伴学对话
8. 下课导出学习数据
9. 回到教师端 → 学情分析 → 上传学习数据 → 查看班级分析报告

## 八、常见问题

### 端口被占用
关闭之前启动的开发服务窗口，或在 `package.json` 中修改各应用的端口配置。

### 学生端无法识别资源包
请确认上传的是教师端「资源导出」页面导出的 JSON 资源包（文件名通常包含 `resource`），不是学生学习数据包。

### 学情分析没有数据
请先在学生端完成学习并导出学习数据 JSON，再回到教师端「学情分析」页面上传。

### 是否需要填写真实 API Key
不必须。系统内置完整的本地规则生成引擎，不配置任何 AI 模型也能完整体验。比赛提交时请勿包含真实 API Key。
