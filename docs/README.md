## 系统概述

课链智教——基于多智能体协同的初中信息科技AI备教学评一体化系统，是一套面向初中信息科技课程的双端智能教学系统。系统由**教师端（备课工作台）**和**学生端（课堂学习端）**组成，通过标准化 JSON 数据包实现双端数据流转，形成"课前智能备课—课中学习记录—课后学情分析"的完整教学闭环。

- **教师端**：`http://localhost:5173`（React + TypeScript + Vite + Tailwind CSS）
- **学生端**：`http://localhost:5174`（React + TypeScript + Vite + Electron 桌面壳）
- **后端服务**：`http://localhost:3000`（Express + LangGraph SSE 工作流）

系统总计约 7100 行代码，包含教师端 9 个页面、学生端 3 个功能标签页、后端 7 个 API 接口和 6 节点 AI 工作流。
