# 课链智教系统技术架构说明

## 一、技术选型

| 层级 | 技术 | 选型理由 |
|------|------|----------|
| 前端框架 | React 18 + TypeScript 5 | 生态成熟，组件化开发，类型安全 |
| 构建工具 | Vite 5 | 快速HMR，TypeScript/JSX开箱即用 |
| 样式方案 | Tailwind CSS 3 | 原子化CSS，快速构建工作台风格UI |
| 后端框架 | Express.js 4 | 轻量HTTP服务，适合API代理和中间层 |
| AI工作流 | LangGraph (StateGraph) | 多节点DAG编排，SSE流式推送 |
| 文档生成 | docx 9.x | 生成真正Word .docx文件 |
| 桌面壳 | Electron + vite-plugin-electron | 学生端桌面应用打包 |
| 包管理 | npm workspaces | monorepo多应用管理 |
| 运行时 | Node.js 20+ | 全栈JavaScript运行环境 |

**核心设计原则**：零外部依赖——无需数据库、无需认证服务、无需云存储、无需消息队列。

## 三、数据架构

### 3.1 存储方案

| 数据类型 | 存储位置 | 生命周期 |
|----------|----------|----------|
| 教师课例数据 | localStorage | 持久化 |
| 教师偏好设置 | localStorage | 持久化，可导出 |
| AI 模型配置 | localStorage | 持久化 |
| 课程数据库 | localStorage | 持久化，支持导入导出 |
| 课堂资源包 | JSON 文件 | 文件流转 |
| 学生学习数据 | JSON 文件 | 文件流转 |
| 学情分析结果 | 内存 | 页面会话期间 |

### 3.2 核心数据结构

**课堂资源包（ClassroomResourcePackage）**：
```
├── teachingNeed           # 教师输入的教学需求
├── curriculumBasis        # 课标与指南依据
├── tpackAnalysis          # TPACK 七维度分析
├── literacyEvidenceChain  # 核心素养证据链
├── teachingDesign         # 完整教学设计
├── learningTaskSheet      # 学习任务单
├── layeredAssessment      # 分层测评题
└── learningDiagnosisTemplate  # 学情诊断模板
```

**学生学习数据包（StudentLearningData）**：
```
├── studentInfo            # 班级、姓名、学号
├── lesson                 # 课题、年级、模块
├── startedAt/finishedAt   # 学习时间
├── taskResponses          # 任务回答（含base64图片）
├── assessmentResponses    # 测评作答（含正确答案）
├── assistantMessages      # AI伴学对话历史
├── progress               # 完成率统计
└── diagnosisSignals       # 四维诊断信号
```

### 3.3 数据流转

```
教师端(生成资源) ──JSON资源包──> 学生端(完成学习)
教师端(学情分析) <──JSON学习数据── 学生端(导出数据)
```

## 四、前端架构

### 4.1 教师端

单文件多页面架构（`App.tsx` 3687行），通过 `useState` 管理页面切换，无需 React Router。

**核心函数**：

| 函数 | 职责 |
|------|------|
| `createResourcePackage()` | 本地规则引擎：生成完整资源包 |
| `matchGuideEntry()` | 加权匹配课程数据库条目 |
| `buildAssistantPreview()` | 本地 AI 修订建议生成 |
| `exportToWord()` | docx 库生成 Word 文档 |
| `exportToHtml()` | 生成 HTML 课堂页 |
| `analyzeClassData()` | 学情分析汇总 |
| `runResourceCheck()` | 七维度资源质量检测 |
| `connectSSE()` | SSE 工作流进度连接 |

### 4.2 学生端

单文件架构（`App.tsx` 913行），320px 手机形态设计。

**核心函数**：

| 函数 | 职责 |
|------|------|
| `parseAssessment()` | 解析测评题为可交互题型 |
| `generateLearningData()` | 生成完整学习数据 JSON |
| `generateRuleBasedReply()` | 本地 AI 伴学回复（苏格拉底式） |

### 4.3 样式

- 教师端：Tailwind CSS + 飞书式工作台风格，左侧220px导航 + 弹性主内容区
- 学生端：320px 固定宽度，模拟手机屏幕，顶部进度条 + 标签页切换 + 对话气泡

## 五、后端架构

### 5.1 Express 服务

7个 API 接口（详见 [功能说明文档](./功能说明文档.md)），中间件：`cors()` + `express.json()`。

### 5.2 LangGraph 工作流

基于 `StateGraph` 的 6 节点 DAG，通过 SSE 实时推送进度：

```
analyzeNeeds → alignCurriculum → generateActivities → generateAssessments → evaluateConfidence → assembleResource
```

**SSE 事件类型**：
- `progress` — 节点进度（当前步骤名、进度百分比、阶段描述）
- `result` — 单个节点完成结果
- `fallback` — 节点回退通知
- `error` — 错误信息
- `done` — 工作流完成（含完整资源包）

### 5.3 三层容错

| 层级 | 范围 | 机制 |
|------|------|------|
| 节点级 | 单个AI调用失败 | 规则引擎生成默认值替代 |
| 图级 | 工作流整体失败 | `fallback.ts` 单次AI调用兜底 |
| 前端级 | 后端不可用 | 前端 `createResourcePackage()` 本地生成 |

### 5.4 AI 接口

- 协议：OpenAI 兼容 `POST /chat/completions`
- 配置优先级：请求体参数 > 环境变量 > 本地规则引擎
- 自动回退：支持 `response_format: json_object`，不支持时自动切换纯文本


## 七、安全设计

- API Key 存于 localStorage，不提交代码仓库
- `.env.example` 仅提供模板格式，`.env` 已加入 `.gitignore`
- 全部数据本地存储，不上传任何远程服务器
- AI 生成内容须经教师确认，资源检测含"AI伦理与安全性"维度
- AI 伴学约束为苏格拉底式引导，不输出不当内容
