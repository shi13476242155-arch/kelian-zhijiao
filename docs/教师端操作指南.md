# 课链智教教师端操作指南

## 一、启动与界面

浏览器访问 `http://localhost:5173`，进入教师工作台。左侧导航按备课流程分组：工作台首页、新建课例、备课工作台、资源检测、资源导出、学情分析、精品案例、课程数据库、系统设置。

## 二、完整备课流程

### 第一步：新建课例

1. 点击左侧「新建课例」
2. 填写课题名称（如"数据分包灵活传"）
3. 选择年级（自动映射课程模块）、课时数
4. 选择课堂类型：

| 教学意图 | 选择课型 |
|----------|----------|
| 讲清楚新概念或原理 | 新知建构课 |
| 带学生做完整项目 | 项目实践课 |
| 让学生通过实验发现规律 | 实验探究课 |
| 训练工具操作技能 | 技能应用课 |
| 综合主题跨学科学习 | 跨学科主题课 |

5. 填写学生基础和设备条件（可选点「AI 帮我写」自动生成）
6. 可选：填写教学目标、重点、难点（点「试试 AI 帮我写」起草）
7. 可选：勾选个性化标签（项目式学习、真实情境、计算思维等）
8. 点击「下一步：进入备课工作台」

### 第二步：生成课堂资源包

进入备课工作台后选择生成方式：

**快速生成**：点击「生成课堂资源包」→ 单次调用 AI，15-30秒完成。

**深度生成（推荐）**：点击「深度生成」→ 启动 LangGraph 6节点 SSE 工作流，实时查看每个阶段的进度（需求分析→课标对齐→活动生成→测评生成→置信度评估→资源组装），2-3分钟完成，质量更高。

生成内容包括：教学设计、学习任务单、分层测评题、学情诊断表、课堂材料。

### 第三步：修改与完善

**直接编辑**：点击任意内容块文字直接修改。可修改的内容包括教学目标每条文字、教学流程每个环节的教师/学生活动、任务单要求、测评题选项、诊断表维度等。

**AI 修订助手**：
1. 点击想要修改的内容区域
2. 从7个快捷方向中选择（优化流程/增加追问/降低难度/增加评价/改得更具体/增强情境/补充素养），或输入自定义需求
3. 查看 Diff 预览（原文红色、建议绿色、修订理由）
4. 确认点击「应用」，否则点击「放弃」

> AI 修订建议不会自动覆盖教师正文，必须确认后才应用。

**切换课型**：顶部课型选择器可中途切换，教学流程自动更新。

**保存确认**：
- 「保存修改」→ 资源状态变为「教师修改版」
- 「确认定稿」→ 资源状态变为「教师确认版」，优先用于检测和导出

### 第四步：资源质量检测

1. 点击左侧「资源检测」
2. 系统自动展示：
   - 总体置信度（环形图）
   - 导出建议（绿/黄/红）
   - 七维度评估卡片（含分数、证据、风险、改进建议）
   - 4条核心素养证据链可视化（目标→活动→任务证据→测评证据→评价方法）
3. 根据建议返回完善，或确认后进入导出

### 第五步：导出资源

1. 点击左侧「资源导出」
2. 选择格式：

| 格式 | 用途 |
|------|------|
| Word (.docx) | 打印提交、教学存档 |
| HTML | 课堂大屏展示 |
| JSON | 发给学生端使用 |

> 建议确认定稿后再导出，确保版本最新。

### 第六步：学情分析（课后）

1. 收集学生提交的学习数据 JSON 文件
2. 点击「学情分析」，批量上传学生数据文件
3. 查看班级学情报告：班级人数、任务/测评完成率、核心素养表现、学生三层分层、薄弱点排序、教学改进建议

## 三、其他功能

### 精品案例

点击「精品案例」→ 浏览内置案例 → 点击「载入为新案例」→ 在备课工作台中修改适配。

### 课程数据库

点击「课程数据库」→ 按年级/模块浏览192条条目 → 支持搜索、新增、编辑、删除、导入/导出 JSON。AI 生成时自动匹配。

### 系统设置

- AI 模型配置：API Base URL、Model Name、API Key，点「测试连接」验证
- 个人偏好：默认年级、课时、课型、设备条件、导出风格（简洁版/教研版/比赛版）
- 数据管理：清除课例、恢复默认、导出/导入设置

## 五、常见问题

**Q：生成资源需要多长时间？** 本地引擎几乎即时；快速AI模式15-30秒；深度SSE工作流2-3分钟。

**Q：不配置AI能用吗？** 可以。系统内置完整的本地规则引擎，全部功能可用。

**Q：换电脑后课例还在吗？** 课例存在浏览器localStorage中，换电脑需导出JSON备份。
