# 课链智教数据包规范说明

## 一、设计目标

系统采用 JSON 数据包作为教师端、学生端和后端之间的数据交换格式。设计目标：
1. 结构清晰，便于前端读取展示
2. 字段稳定，便于后续扩展
3. 可导出、可上传、可迁移
4. 不依赖账号系统

## 二、课堂资源包（ClassroomResourcePackage）

教师端生成并导出，学生端导入使用。

### 2.1 顶层结构

```json
{
  "id": "resource-xxxx",
  "generatedAt": "2026-05-17T00:00:00.000Z",
  "teachingNeed": {},
  "curriculumBasis": {},
  "tpackAnalysis": {},
  "literacyEvidenceChain": [],
  "teachingDesign": {},
  "learningTaskSheet": {},
  "layeredAssessment": {},
  "learningDiagnosisTemplate": {}
}
```

### 2.2 TeachingNeed — 教学需求

| 字段 | 含义 | 示例 |
|------|------|------|
| topicName | 课题名称 | "数据分包灵活传" |
| grade | 年级 | "七年级" |
| courseModule | 课程模块 | "互联网应用与创新" |
| classHours | 课时数 | "1课时" |
| studentFoundation | 学生基础 | "学生已能使用浏览器上网..." |
| equipmentCondition | 设备条件 | "一人一机，Windows 10..." |
| teachingObjectives | 教学目标 | ["目标一...", "目标二...", "目标三..."] |
| teachingFocus | 教学重点 | "理解数据分包传输..." |
| teachingDifficulty | 教学难点 | "理解存储转发..." |
| lessonType | 课堂类型 | "新知建构课" |
| generationScope | 生成范围 | "full" |
| additionalNeeds | 个性化标签 | ["项目式学习", "真实情境"] |
| updatedAt | 更新时间 | ISO时间戳 |

### 2.3 CurriculumBasis — 课标依据

| 字段 | 含义 |
|------|------|
| standards | 课程标准条目 |
| teachingGuides | 教学指南条目（从课程数据库匹配） |
| coreLiteracy | 核心素养维度（信息意识/计算思维/数字化学习与创新/信息社会责任） |

### 2.4 TpackAnalysis — TPACK 七维度分析

| 维度 | 含义 |
|------|------|
| ck (Content Knowledge) | 学科内容知识 |
| pk (Pedagogical Knowledge) | 教学法知识 |
| tk (Technological Knowledge) | 技术知识 |
| pck | 学科教学知识（CK∩PK） |
| tck | 技术内容知识（TK∩CK） |
| tpk | 技术教学知识（TK∩PK） |
| tpack | 技术-教学-内容综合知识 |

### 2.5 LiteracyEvidence — 核心素养证据链

| 字段 | 含义 |
|------|------|
| literacy | 核心素养名称 |
| teachingObjective | 对应的教学目标 |
| learningActivity | 对应的学习活动 |
| taskEvidence | 任务单中的学生证据 |
| assessmentEvidence | 测评题中的学生证据 |
| evaluationMethod | 评价方式 |
| achievementStatus | 达成状态（绿/黄/红） |
| riskAlert | 风险提示 |
| improvementSuggestion | 改进建议 |

### 2.6 TeachingDesign — 教学设计

| 字段 | 含义 |
|------|------|
| basicInfo | 课题、年级、模块、课时等基本信息 |
| curriculumAnalysis | 课标与指南分析 |
| learningAnalysis | 学情分析 |
| teachingAnalysis | 教学分析 |
| teachingMethods | 教学方法 |
| teachingObjectives | 四条核心素养教学目标 |
| keyAndDifficultPoints | 重点与难点 |
| resourcesAndEnvironment | 教学资源与环境 |
| procedures | 教学流程数组（TeachingProcedure[]） |
| questionChain | 问题链设计 |
| evaluationDesign | 评价设计 |
| blackboardDesign | 板书设计 |
| reflectionSuggestions | 教学反思建议 |

### 2.7 TeachingProcedure — 教学流程环节

| 字段 | 含义 |
|------|------|
| phase | 教学环节名称 |
| duration | 建议时间 |
| keyQuestion | 关键问题或教师追问 |
| teacherActivity | 教师活动 |
| studentActivity | 学生活动 |
| designIntent | 设计意图 |

### 2.8 LearningTaskSheet — 学习任务单

| 字段 | 含义 |
|------|------|
| taskGoal | 学习目标 |
| scenarioIntroduction | 情境导入 |
| taskSteps | 学习任务步骤 |
| learningSupports | 学法指导 |
| groupRoles | 小组角色 |
| recordTable | 操作记录表 |
| reflectionQuestions | 课堂反思问题 |

### 2.9 LayeredAssessment — 分层测评题

| 字段 | 页面题型 | 考查层次 |
|------|----------|----------|
| basicUnderstanding | 单选题（2题） | 基础概念理解与辨析 |
| principleExplanation | 判断题（1题） | 原理性知识判断 |
| scenarioTransfer | 简答题（1题） | 过程表达与情境迁移 |
| creativeExpression | 分析题选做（1题） | 开放表达与创新思维 |

### 2.10 LearningDiagnosisTemplate — 学情诊断模板

| 字段 | 含义 |
|------|------|
| evaluationDimensions | 评价维度（概念理解、过程表达、迁移能力、责任意识） |
| dataSources | 数据来源（任务单、测评题、AI伴学记录） |
| dataTracking | 数据采集项与采集方式 |
| dataFormat | 数据格式 |
| diagnosisRules | 诊断规则与判读标准 |
| outputResults | 输出结果模板 |

## 三、学生学习数据包（StudentLearningData）

学生端导出，教师端学情分析导入。

### 3.1 顶层结构

```json
{
  "id": "student-data-xxxx",
  "exportedAt": "2026-05-17T00:00:00.000Z",
  "studentInfo": {},
  "lesson": {},
  "startedAt": "",
  "finishedAt": "",
  "taskResponses": [],
  "assessmentResponses": [],
  "assistantMessages": [],
  "progress": {},
  "diagnosisSignals": {}
}
```

### 3.2 字段说明

| 模块 | 字段 | 含义 |
|------|------|------|
| studentInfo | className, studentName, studentNumber | 班级、姓名、学号 |
| lesson | title, grade, module | 课题、年级、模块 |
| 时间 | startedAt, finishedAt | 学习开始/结束时间 |
| taskResponses | id, prompt, response, imageBase64 | 任务编号、要求、回答、图片 |
| assessmentResponses | id, type, prompt, response, correctAnswer | 题目编号、题型、题目、作答、正确答案 |
| assistantMessages | role, content, time | 角色(student/assistant)、内容、时间戳 |
| progress | taskCompletionRate, assessmentCompletionRate | 任务/测评完成率(0-1) |
| diagnosisSignals | conceptUnderstanding, processExpression, transferAbility, responsibilityAwareness | 四维诊断信号 |

## 四、SSE 工作流事件类型

深度生成模式通过 SSE 推送的事件类型定义：

### WorkflowProgressEvent
```json
{
  "type": "progress",
  "step": "generateActivities",
  "percent": 40,
  "message": "正在设计教学活动..."
}
```

### WorkflowResultEvent
```json
{
  "type": "result",
  "step": "alignCurriculum",
  "data": { /* 节点输出数据 */ }
}
```

### WorkflowFallbackEvent
```json
{
  "type": "fallback",
  "step": "generateActivities",
  "message": "AI 调用失败，已使用本地引擎生成",
  "data": { /* 回退数据 */ }
}
```

### WorkflowErrorEvent
```json
{
  "type": "error",
  "message": "工作流执行异常"
}
```

### WorkflowDoneEvent
```json
{
  "type": "done",
  "resourcePackage": { /* 完整 ClassroomResourcePackage */ }
}
```

## 五、数据流转

```
教师端(生成) ──ClassroomResourcePackage JSON──> 学生端(导入)
学生端(学习) ──StudentLearningData JSON──> 教师端(学情分析)
后端(工作流) ──SSE events──> 教师端(进度展示)
```

## 六、数据安全

- 项目代码中不写入真实 API Key
- 学生学习数据仅用于课堂分析和教学改进
- 本地数据存于 localStorage，不上传远程服务器
- JSON 数据包不含身份认证信息
