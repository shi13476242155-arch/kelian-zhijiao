# 课链智教开发历程与质量报告

## 一、项目概述

课链智教——基于多智能体协同的初中信息科技AI备教学评一体化系统，由一线信息科技教师借助生成式AI（Claude、DeepSeek等）辅助完成需求分析、界面设计、代码编写与文档生成全流程。系统约7100行代码，从最小可运行版本逐步发展为教师端9页面、学生端双形态（浏览器+Electron桌面）、后端7接口+LangGraph 6节点SSE工作流的完整产品。

---

## 二、开发背景与问题定位

初中信息科技课程一线教学中存在五个结构性难题：
1. 备课材料（教学设计、任务单、测评题、诊断表）分别编制，彼此割裂
2. 核心素养目标常在教案中仅作文字表述，未能嵌入学习活动与评价
3. 五种课型教学逻辑差异显著，但传统教案采用单一模板
4. 学生课堂学习数据无法系统采集，学情分析依赖主观经验
5. 通用AI教案工具缺少课程标准与学情条件的结构化输入

项目本质不是做一个"AI写教案"工具，而是将课程标准、教学设计理论、学情数据与AI能力有机整合，形成备课—上课—分析的完整闭环。

## 三、完整版本演进

### V0 — 最小可运行版本
建立 monorepo 项目结构（pnpm workspaces），完成教师端首页、左侧导航、Express后端基础接口、README、TODO、样例数据和环境变量示例。确保项目能本地启动和构建。

### V1 — 新建课例与教学需求输入
新建课例页面、TeachingNeed 类型定义、课题/年级/模块/课时/学情/设备条件字段、五种课堂类型选择、个性化生成向导、localStorage 本地保存。让教师以教学语言输入一节课的生成需求。

### V2 — Mock 资源生成
根据 TeachingNeed 本地规则引擎生成完整课堂资源包：课程依据、TPACK分析、核心素养证据链、教学设计、学习任务单、分层测评题、学情诊断表。初步建立"课程标准—核心素养—教学活动—评价证据"的资源结构。

### V2.5 — 备课工作台
合并资源生成和修订入口，形成统一备课工作台，支持资源生成、直接编辑、保存修改和确认定稿。

### V2.6 — AI 修订助手
在备课工作台中加入 AI 修订助手，支持7个快捷修订方向。AI建议不自动覆盖正文，需教师确认应用。建立"AI建议—教师确认—资源修改"的可控机制。

### V2.7 — 内容架构分层
将课标依据、TPACK和素养证据链从主编辑区移至右侧辅助面板。主编辑区聚焦教师直接使用的课堂资源（教学设计、任务单、测评题、诊断表）。任务单和测评题调整为更适合学生端使用的格式。

### V3 — 资源检测
融合素养证据链和质量评估，七维度检测（课标一致性、素养达成度、学情贴合度、活动可操作性、资源完整度、学生端兼容性、AI伦理安全性），输出置信度环形图、导出建议和一句话体检结论。

### V4 — 资源导出
支持JSON导出、HTML课堂页导出、真正Word(.docx)导出。Word按正式教学文档结构生成（7章节+附录）。建立版本追踪机制。

### V5 — 学生端
新建 `apps/student`：上传教师端JSON资源包、填写学生信息、任务单（含图片上传）、测试题（4种题型）、AI伴学（苏格拉底式引导）、下课导出学习数据JSON。

### V6 — 学情分析
教师端支持批量上传学生数据包，生成班级总览（完成率、薄弱点）、核心素养表现、三层学生分层（稳定掌握/需要支架/继续观察）、薄弱点排序和教学改进建议。完成"学生数据回流→教师学情分析"闭环。

### V7 — 工作台视觉优化
教师端采用飞书式轻量工作台视觉，左侧导航分组可折叠，新建课例增加课型说明，主编辑区+右侧辅助面板布局定型。

### V8 — AI 工作流升级（LangGraph + SSE）
- 引入 LangGraph StateGraph，将资源生成拆分为6节点DAG
- 实现 SSE 流式推送，教师可实时查看每个智能体的工作进度
- 双模式架构：快速生成（单次调用，15-30秒）+ 深度生成（6节点SSE工作流，2-3分钟）
- 三层容错体系：节点级回退 → 图级回退 → 前端级回退
- workflow/ 目录：5个节点实现 + 2个提示词模块 + 状态管理 + SSE + fallback

### V9 — 学生端增强与 Electron 桌面壳
- 学生端增加 AI 伴学上下文感知（附带当前课题、任务、学习目标）
- Electron 桌面壳（400px宽，屏幕92%高，右侧定位）
- vite-plugin-electron 集成，支持开发/生产双模式
- 课程数据库更新为192条完整条目
- 学情分析增强四维诊断信号

### V10 — 系统完善与文档定型
- 全面代码审查与优化，总计约7100行
- 52项测试用例全部验证通过
- 9份文档完整覆盖安装、功能、操作、架构、AI设计、数据规范、理论依据、评价标准

## 四、技术平台

- 前端：React 18 + TypeScript 5 + Vite 5 + Tailwind CSS 3
- 后端：Node.js + Express 4 + LangGraph
- AI：OpenAI 兼容协议，适配 DeepSeek/通义千问/智谱GLM
- 桌面：Electron + vite-plugin-electron
- 文档：docx 9.x（Word生成）
- 架构：npm workspaces monorepo，零数据库依赖

## 五、关键问题与解决

**1. 资源生成内容不够贴近真实课堂** → 引入五种课型差异化流程、个性化生成标签、课程数据库匹配

**2. TPACK和素养证据链过重** → 从主编辑区移至右侧辅助面板，主编辑区聚焦教师直接使用的资源

**3. 双端数据如何衔接** → 标准化 JSON 数据包：ClassroomResourcePackage（教师→学生）+ StudentLearningData（学生→教师）

**4. AI生成质量不稳定** → 三层提示词注入（角色+知识+约束）+ 三层容错（节点→图→前端）

**5. 单次AI调用质量有限** → LangGraph 6节点工作流拆解任务，每节点独立优化提示词和容错

**6. 构建稳定性** → 调整Vite根目录配置和构建脚本路径

## 七、应用场景与效果

### 典型场景
以七年级"数据分包灵活传"为例：教师选择新知建构课→系统匹配6环节流程→填写学情和设备条件→勾选"真实情境""计算思维"标签→深度生成5模块资源→教师修订"迁移应用"环节→通过七维检测→导出Word(教研使用)+HTML(课堂展示)+JSON(学生端分发)→学生完成任务和测评→与AI伴学互动→教师回收全班数据→学情看板显示薄弱点→调整下节课设计。

### 应用效果
- **备课效率**：从传统3-4小时压缩至30-40分钟（含AI生成+教师确认），效率提升约5-6倍
- **资源标准化**：五模块标准化输出，双端精确兼容
- **学情数据化**：学生作答、测评、AI对话转化为可量化数据
- **素养落地**：四项素养转化为"目标—活动—任务证据—测评证据—评价方式"五节点证据链

## 八、核心创新

1. **课程标准与课型流程双重约束AI生成**：将课标、课型定义、学情条件作为结构化约束注入提示词
2. **"素养证据链"教学设计方法论**：将核心素养从目标表述转化为可检查证据链
3. **人机协同修订确认机制**：AI建议以Diff预览，教师确认方应用，未确认内容阻断导出
4. **双端数据闭环**：标准化JSON数据包实现课前—课中—课后数据流转
5. **LangGraph多智能体SSE工作流**：6节点DAG编排+实时进度可视化+三层容错
6. **AI赋能一线教师自主开发**：无编程背景的教师借助AI完成全流程开发
