## 三、导向性说明

### 1. 价值导向正确

课链智教坚持立德树人根本任务，系统设计以学生发展为中心，不把 AI 作为替代教师和替代学生思考的工具，而是作为辅助教师备课、辅助学生学习和辅助教师分析学情的智能助手。

系统在教学资源中重点体现：

1. 信息意识：引导学生从真实生活中发现信息问题。
2. 计算思维：引导学生分解问题、表达过程、建立模型。
3. 数字化学习与创新：引导学生使用数字工具记录、表达和改进。
4. 信息社会责任：引导学生关注隐私保护、数据安全、规范表达和负责任使用技术。

在 AI 伴学设计中，系统不直接替学生给出完整答案，而是提供思路拆解、任务提醒和表达支架，帮助学生形成自主学习能力。

### 2. AI 赋能开发

项目开发过程充分体现生成式人工智能对教师专业成长和跨界开发能力的支持。一线教师可以借助 AI 完成需求梳理、界面设计、代码生成、文档撰写和教学资源结构设计，从而跨越自身在软件工程、前端开发和智能应用开发方面的限制。

该过程体现了教师终身学习、主动适应人工智能时代教育变革的实践价值。

## 四、实用性说明

### 1. 有效解决真实问题

系统解决的核心问题来自真实教学场景：

1. 教师备课时间有限，完整资源包准备负担重。
2. 信息科技课堂活动多，但任务单、测评题和诊断表常常分散。
3. 核心素养难以从目标落实到活动和评价证据。
4. 学生课堂学习过程难以被记录和回收。
5. 课后学情分析缺少数据支撑。

课链智教通过教师端和学生端协同，形成可执行解决方案：

1. 教师输入教学需求。
2. 系统生成课堂资源包。
3. 教师修改并确认定稿。
4. 学生端导入资源包完成学习。
5. 学生端导出学习数据。
6. 教师端上传数据生成学情分析。

### 2. 操作简单易用

系统采用本地 Web 应用方式运行，不要求教师配置复杂服务器。教师只需通过浏览器访问教师端，学生通过浏览器访问学生端。

易用性体现在：

1. 使用左侧导航组织教师工作流程。
2. 新建课例页面使用教师熟悉的教学语言。
3. 备课工作台支持点击内容直接修改。
4. 资源导出提供 Word、HTML、JSON 三种常见格式。
5. 学生端流程简单，上传资源包后即可学习。
6. 学情分析页面支持批量上传学生数据包。

## 五、影响力说明

### 1. 开源分享价值

课链智教使用 React、TypeScript、Vite、Tailwind CSS、Express 等通用开源技术构建，项目结构清晰，便于其他教师、学校或教研团队学习和二次开发。

项目具备推广条件：

1. 本地可运行，不强依赖复杂部署。
2. 数据包格式清晰，便于跨设备传递。
3. 文档体系完整，便于他人复现。
4. 样例课例可替换，便于校本化应用。
5. 后续可接入不同 OpenAI 兼容模型服务。

### 2. 真实落地基础

系统设计紧扣真实课堂流程，而非仅用于展示。教师可以用真实课题创建资源，学生端可以在课堂中使用，教师课后可以导入学习数据形成分析报告。

当前系统已经具备真实试用基础：

1. 教师端可生成并导出课堂资源包。
2. 学生端可导入资源包并完成学习。
3. 学生学习数据可回传教师端。
4. 教师端可生成班级学情分析和教学改进建议。

## 六、创新性说明

课链智教的创新不在于单点功能，而在于应用模式和技术组合。

主要创新包括：

1. 双端协同：教师端生成资源，学生端使用资源并回传数据。
2. 数据包流转：通过 JSON 资源包和学生学习数据包实现无数据库条件下的数据闭环。
3. 课型驱动：不同课堂类型对应不同教学流程和教学方法。
4. 证据链检测：将核心素养落实到目标、活动、任务证据、测评证据和评价方式。
5. AI 可控修订：AI 建议需要教师确认后应用，体现教师主体性。
6. 多格式导出：同一资源包可导出为 Word、HTML 和 JSON，兼顾教学、展示和扩展。
